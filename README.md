# Aurum — Gaming Interface Concept

A front-end design study: a dense, real-time gaming dashboard built in vanilla HTML, CSS and JavaScript.
No framework, no build step, no dependencies.

**This is a concept, not a product.** No accounts, no payments, no gameplay. Every figure on the page is placeholder data.

## Running it

Open `index.html`, or serve the folder:

```
python -m http.server 8080
```

## Notes

- Single file, ~60KB, zero dependencies
- CSS custom properties for theming; responsive from 320px
- Marked `noindex` — it is a portfolio piece, not a site meant to be found in search
